# MONO. — グレースケール画像変換ツール

ブラウザで画像を読み込み、グレースケールの強さを調整してPNG形式で保存できるWebアプリです。画像の処理はすべてブラウザ内で行います。

[アプリを開く](https://kichouji.github.io/grayscale-studio/)

## 使い方

1. 画像を選択するか、ドラッグ＆ドロップで読み込みます。
2. スライダーでグレースケールの強さを調整します。
3. 「PNGをダウンロード」をクリックして保存します。

ローカルでは `index.html` をブラウザで開いて利用できます。
